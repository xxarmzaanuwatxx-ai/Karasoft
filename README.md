# KaraSoft

โปรแกรมคาราโอเกะจอเดียวสำหรับไฟล์ NCN (.mid + .lyr + .cur) และ EMK เล่นดนตรีด้วย SoundFont ผ่าน FluidSynth

## การใช้งาน

| ทำอะไร | วิธี |
|---|---|
| เปิดเพลง | คลิกขวา > เปิดเพลง, Ctrl+O หรือลากไฟล์ .emk / .mid มาวางบนจอ (เลือกหลายเพลงได้ จะเข้าคิวเล่นต่อกัน) |
| เพิ่ม SoundFont | คลิกขวา > SoundFont > เพิ่ม SoundFont หรือลากไฟล์ .sf2 มาวาง ใส่ได้หลายไฟล์ ไฟล์ที่เพิ่มทีหลังจะใช้แทนเสียงที่ซ้ำกันของไฟล์ก่อนหน้า |
| แผงปรับดนตรี 16 ช่อง | เลื่อนเมาส์ไปขอบบนสุดของจอ |
| Synth Mixer 32 ช่อง + VST | คลิกขวา > Synth Mixer หรือปุ่มบนแผงดนตรี ช่อง 1-16 คือแชนแนล MIDI ช่อง 17-32 คือกลองแยกชิ้น (กระเดื่อง สแนร์ ไฮแฮท ทอม ฉาบ ฯลฯ) แต่ละช่องใส่ปลั๊กอิน VST3 ได้ 4 ตัว |
| ฟอนต์ ขนาด สี | คลิกขวา > ตัวอักษร |
| คีย์ / จังหวะ | ลูกศรขึ้น-ลง เปลี่ยนคีย์ หรือคลิกขวา > คีย์ / จังหวะ |
| ทำนองนำ | ปุ่ม M เปิด/ปิดเสียงทำนองนำ |
| เล่น/หยุด | Space เล่น/หยุดชั่วคราว, Esc หยุด, ซ้าย-ขวา เลื่อน 5 วินาที, PgDn เพลงถัดไป, F11 เต็มจอ |

โครงสร้างโฟลเดอร์ NCN แบบมาตรฐาน (`Song/`, `Lyrics/`, `Cursor/`) หรือวางทั้งสามไฟล์ในโฟลเดอร์เดียวกันก็ได้

## รูปแบบไฟล์

- **NCN**: `.lyr` เป็นข้อความ TIS-620 บรรทัด 1-4 คือ ชื่อเพลง, ศิลปิน, คีย์, บรรทัดว่าง เนื้อร้องเริ่มบรรทัดที่ 5
  `.cur` เป็น uint16 ต่อ 1 ไบต์ของเนื้อร้อง (ไม่นับขึ้นบรรทัดใหม่) หน่วยเป็น ppq/24 tick
- **EMK**: ทั้งไฟล์ XOR ด้วยคีย์ 8 ไบต์ `AF F2 4C 9C E9 EA 99 43` ได้ส่วนหัว `.SFDS` ที่ชี้ไปยังตารางบล็อก
  (HEADER, SONG_INFO, MIDI_DATA, LYRIC_DATA, CURSOR_DATA) แต่ละบล็อกบีบอัดด้วย zlib ส่วนเนื้อร้อง/เคอร์เซอร์เหมือน NCN

## การ build

ต้องใช้ CMake 3.22+ และคอมไพเลอร์ C++17 (JUCE 8 จะถูกดาวน์โหลดอัตโนมัติ หรือกำหนด `-DJUCE_DIR=...`)

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

FluidSynth 2.2+ ถูกโหลดตอนรันโปรแกรม: บน Windows วาง `libfluidsynth-3.dll` และ DLL ที่ต้องใช้ไว้ข้าง `KaraSoft.exe`
บน Linux ติดตั้ง `libfluidsynth3`

ตัวติดตั้ง Windows (`KaraSoft-Setup-x.y.z.exe`) สร้างอัตโนมัติด้วย GitHub Actions (`.github/workflows/build-windows.yml`)
ทุกครั้งที่ push ดาวน์โหลดได้จากหน้า Actions > Artifacts

เครื่องมือทดสอบ: `karaparse <เพลง>` แสดงเนื้อร้องพร้อมเวลา, `kararender <เพลง> <sf2> <out.wav>` เรนเดอร์เสียงเป็นไฟล์ WAV
